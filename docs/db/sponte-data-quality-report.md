## Cross-File Findings



- `Alunos` has missing CPF values and one malformed CPF example, so CPF cannot be the sole identity key.

- `Responsaveis` also has missing CPF values, so family derivation must rely primarily on explicit relationship rows.

- `AlunosEmpresas.CursoID` is denormalized and should not be treated as a clean FK without a parsing rule.

- `ContasReceber` includes non-student finance rows (`AlunoID = 0`), so finance import must support student-linked and non-student charges separately.

- `Anexos` is metadata only; do not assume file binaries are available from this export.

- `ContasReceberParcelas.Situacao` and some class/enrollment status codes still require business confirmation before final UI labels.
